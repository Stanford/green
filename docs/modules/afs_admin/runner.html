afs_admin.runner¶

A command runner class

The Runner class is used to run command-line commands like vos, fs, pts, etc.

This class does _not_ return AFS objects like Volume or AFSFileServer, rather, it returns the text output of command.

exception stanford.green.afs_admin.runner.AFSNoRunnerError¶

Raised when an expecetd Runner is missing.
