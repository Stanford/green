afs_admin.runner¶

A command runner class

The Runner class is used to run command-line commands like vos, fs, pts, etc.

This class does not return AFS objects like Volume or AFSFileServer, rather, it returns the text output of command.

class stanford.green.afs_admin.runner.Runner(config: AFSConfig, command_interface: RunnerInterface, verbose: bool = False)[source]¶

The Runner class.

Parameters:

  • config (AFSConfig) – an AFSConfig object; this is required as the AFSConfig object tells the Runner object which cell to use.

  • command_interface (RunnerInterface) –

    which interface this code uses to get AFS information. Currently there are only two recognized interfaces: “direct” and “afsapi”.

    The “direct” interface uses AFS program calls (vos, pts, etc.). The “afsapi” uses calls to the AFS-API service.

run_vos(subcommand: str, vos_arguments: list[str], output_file: Path | None = None) → str | None[source]¶

Run a vos command.

Parameters:

  • subcommand – the vos “action” (e.g., examine or listfs).

  • vos_arguments – the rest of the command-line arguments to pass to vos subcommand.

  • output_file – if this parameter is passed, instead of returning the standard output as a string save standard output to the file specified by output_file; note that this will overwrite output_file.

Returns:

the standard output of the vos command unless the output_file parameter is provided, in which case nothing is returned.

If the output_file parameter is provided this function returns None.

We run all vos commands with the TZ environment variable set to UTC.

For an example of use, see Runner.run_vos_examine().

run_vos_eachfs(format_string: str | None = '%hv,%pv,%nhv,%U') → str[source]¶

Return a list of file server information using the vos eachfs command.

Parameters:

format_string – the output format. The default format string is %hv,%pv,%nhv,%U which translates to hostname,volume server port,ip address,UUID. If format_string is set to None then the default format for vos_eachfs will be used. See the vos eachfs manpage for more information on the format string.

Returns:

the standard output of the vos eachfs command.

Example: Here is how the output string will look (with the default format string):

171.64.16.64,7005,171.64.16.64,NO_UUID
afssvr-sec01.stanford.edu,7005,171.67.217.5,93420e13-71f9-4d7a-8051-786c640e6c5b
afssvr06.stanford.edu,7005,171.67.22.19,b48bfb68-5216-402c-b1c5-b32cfa5ed136
afssvr07.stanford.edu,7005,171.67.22.17,ffee8568-7446-48ad-baea-7365fba78080

Note

If the file server does not have a UUID the string “NO_UUID” will be shown.
